MCA Course Overview

Course Details

Course : Master of Computer Applications (MCA)

Duration : 2 Years

Eligibility : Degree with Mathematics / Computer Science

Focus Areas : Programming, AI, ML, Cloud Computing, Data Science

Programming Languages

Java, Python, C++, JavaScript, PHP and modern web technologies are taught with practical lab sessions.

Core Subjects

Data Structures, DBMS, Operating Systems, Computer Networks, Software Engineering and Web Technology.

Advanced Technologies

Artificial Intelligence, Machine Learning, Cloud Computing, Cyber Security and Data Analytics.

Seat Distribution

  • 30% of seats are filled through COMEDK UGET counseling process.
  • 25% of seats are allocated through Institutional Management Quota.
